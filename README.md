# html-miku-beats-deluxe
Браузерная ритм-игра по мотивам osu! в стилистике Hatsune Miku (HTML)
# 🎵 Miku Beats ♪ Deluxe Edition — v1.0.0

Легковесная веб-ритм-игра, объединяющая динамику **osu!** и стилистику **Hatsune Miku**. Полностью автономная игра в одном файле без необходимости сборки и сторонних серверов.

---

### ⚡ Ключевые возможности:

* 🎧 **Встроенный Web Audio синтезатор:** 6 полноценных процедурных треков (J-Pop, Eurobeat, 8-Bit Chiptune, J-Core, Future Bass, Speedcore) генерируются в реальном времени.
* 📦 **Поддержка карт osu!:** возможность загружать архивы `.osz` и карты `.osu` — игра распаковывает их через JSZip и переносит ноты на игровое поле.
* 📱 **Кроссплатформенность:**
  * **ПК:** классическое управление мышью + клавишами [Z] / [X] (назначаются в настройках), трейлы курсора и Key Overlay.
  * **Смартфон/Планшет:** режим Direct Tap с оптимизированными хитбоксами под пальцы.
* 🎛 **Система модификаторов:** Auto-bot, Relax, Sudden Death (одна ошибка = проигрыш), Double Time (1.4x), Hard Rock (-25% размер кругов), Mirror.
* 🎯 **Киберспортивный HUD:** Hit Error Bar (шкала «Рано / Поздно»), индикатор комбо, точность в %, градация попаданий (300 / 100 / 50 / Miss).
* 🏆 **Локальные рекорды:** таблица лидеров и сохранение личных рекордов в браузере (LocalStorage).
* 🎨 **Кастомизация:** возможность загрузить своё фото или аватарку Мику.

---

### 🛠 Технический стек:
* **HTML5 Canvas** (высокая производительность 60+ FPS)
* **Web Audio API** (синтез звука, спектральный эквалайзер, фильтры)
* **Tailwind CSS** (современный неоновый UI)
* **JSZip** (распаковка архивов на клиенте)
